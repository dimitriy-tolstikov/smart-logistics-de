# Статус репозитория

Этот файл раньше описывал промежуточный аудит и больше не совпадал с кодом. Актуальное описание решения — в [README.md](README.md).

Кратко по текущей версии:

- Обязательный контур: PostgreSQL 17, идемпотентный ELT, карточка маршрута, CatBoost с окнами от `AS_OF_DATE`.
- Backfill пересобирает и старый маршрут, если сделка въехала в окно с другой датой и другим городом.
- Модель v3 учится на ставках перевозчика (`price_type` 3 и 9), хранит каноническую группу кузова и вес, использует лаг медианы прошлого месяца. Метрики пишутся в `etl_meta.ml_runs`. Числа v2 в README относятся к предыдущему таргету.
- ClickHouse синхронизируется через `EXCHANGE TABLES`. Прямой запуск модуля не смотрит на `CLICKHOUSE_SYNC_ENABLED`.
- Superset ходит в ClickHouse по `clickhousedb+connect` на порт 8123. Ошибка посева дашборда роняет init.
- Airflow: `ul_etl_daily` грузит один data interval без обучения; `ul_etl_ml_clickhouse` — ручной полный прогон с моделью.
